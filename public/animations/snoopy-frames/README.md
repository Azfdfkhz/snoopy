# Snoopy Message Garden — PNG Asset Pack

Isi folder `public/animations/snoopy-frames/png/` adalah aset PNG terpisah (satu karakter/objek per file) untuk digunakan pada website.

- 44 file PNG: pose Snoopy, Woodstock, bunga, kupu-kupu, properti taman, awan, dan dekorasi.
- Aset karakter memiliki latar transparan yang diproses dari sprite sheet.
- `sky_background.png` merupakan aset latar langit persegi.
- `snoopy-assets-preview.jpg` adalah lembar pratinjau.

Catatan: aset dipotong dari lembar ilustrasi hasil generasi gambar; beberapa tepi objek kecil mungkin perlu dirapikan sebelum dipakai dalam produksi. Ini adalah aset gambar terpisah, bukan 44 animasi frame-by-frame yang semuanya identik secara gerak.
